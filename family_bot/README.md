# Семейный бот

Личный Telegram-бот Юлии: карточки детей (счета, даты рождения), расписание уроков и звонков,
памятки по оплате, напоминания об оплате питания и платных услуг до 10 числа, напоминания о днях рождения.

**Данные детей в репозитории не хранятся.** Они лежат в файле `data.json` рядом с ботом на сервере
(в `.gitignore`). Резервную копию бот присылает по слову «выгрузить», загрузить данные — отправить боту этот файл.

## Запуск (один раз)

1. В Telegram открыть @BotFather → `/newbot` → придумать имя → получить **токен**.
2. На сервере, который работает круглосуточно (например, машина Hermes):
   ```bash
   pip install -r family_bot/requirements.txt
   export BOT_TOKEN="токен от BotFather"
   python family_bot/bot.py
   ```
3. Написать боту `/start` — он ответит «Нет доступа. Ваш Telegram ID: 123…».
4. Перезапустить бота с этим ID:
   ```bash
   export ALLOWED_IDS="123…"
   python family_bot/bot.py
   ```
5. Отправить боту файл `data.json` — он загрузит данные.

## Настройки (переменные окружения)

| Переменная | Что это | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота | — (обязательно) |
| `ALLOWED_IDS` | кому бот отвечает (через запятую) | никому |
| `DATA_FILE` | где лежат данные | `family_bot/data.json` |
| `TZ_NAME` | часовой пояс | `Europe/Samara` |
| `REMIND_DAYS` | в какие числа напоминать об оплате | `1,5,8,9,10` |
| `REMIND_HOUR` | во сколько напоминать | `10` |

Напоминание об оплате приходит, пока в разделе «Оплата» не нажата кнопка «оплачено» за текущий месяц.
Хостинг должен сохранять файлы между перезапусками, иначе отметки об оплате пропадут.
